                        武将品质分类完整逻辑 v2.0
================================================================================

一、分类数据来源
================================================================================

1. 主表：sgs_general_conf
   - 字段: GeneralID, NamePrefix+GeneralName, LevelTwoGeneralLampType, GetValue
   - 用途: 获取武将基础信息和获取途径
   - 关键: LevelTwoGeneralLampType 优先于 GetValue

2. 获取途径表：sgs_general_activity_operate_info
   - 字段: GeneralID, GeneralName, ActiveDropWay
   - 格式: "获取途径:1001 获取价值:1000"
   - 用途: 确定获取途径(1001纳贤, 1101高山仰止等)

3. 将星价格表：sgs_item_goods_activity_conf
   - 字段: ItemID, ShopType, Price
   - 用途: 确定将星招募价格
   - 流程: GeneralID → sgs_item_general_conf.ItemID → 找将星价格

4. 珍宝定价表：新三国杀道具定价表.xlsx
   - 字段: item_id → price
   - 用途: 确定珍宝/运营活动定价
   - 规则: Price ≥ 10万 → 传说, Price ≥ 1万 → 史诗, etc.

|-----------|----------|-------|------------------|

| 1102      | 武庙珍藏 | 限定  | 固定限定档(LampType) |
| 1004      | 祈福     | 传说  | 固定传说档        |
| 1001      | 纳贤     | 史诗  | 固定史诗档        |
| 5002      | 神将任务 | 史诗  | 固定史诗档        |
| 2000      | 首充     | 史诗  | 固定史诗档        |
| 2002      | 充值奖励 | 史诗  | 固定史诗档        |
| 2003      | 累充奖励 | 史诗  | 固定史诗档        |
| 3001      | 山河令   | 史诗  | 固定史诗档        |
| 1005      | 星河宝箱 | 史诗  | 固定史诗档        |

【第二优先级】将星招募价格 (只要有这个途径就优先执行)
--------------------------------------------------------------
| 价格区间           | 品质  | 说明              |
|-------------------|-------|------------------|
| ≥ 10,000          | 传说  | 将星价格≥1万     |
| 2,000 ~ 9,999     | 史诗  | 将星价格2000-9999|
| 100 ~ 1,999 | 稀有  | 将星价格100-2000 |
| < 100             | 普通  | 将星价格<100     |

【第三优先级】珍宝+运营活动定价 (1003)
--------------------------------------------------------------
| 价格区间           | 品质  | 说明              |
|-------------------|-------|------------------|
| ≥ 200,000         | 限定  | 珍宝价格≥20万    |
| 100,000 ~ 199,999  | 传说  | 珍宝价格10-20万  |
| 10,000 ~ 99,999    | 史诗  | 珍宝价格1-10万   |
| 1,001 ~ 9,999      | 稀有  | 珍宝价格1001-1万 |
| ≤ 1,000            | 普通  | 珍宝价格≤1000    |

【第四优先级】待手动确认
--------------------------------------------------------------
不属于以上分类的武将，整理列表后手动确认评级。

================================================================================
三、分类决策树
================================================================================

对于每个武将，按以下顺序判断:

步骤1: 检查获取途径(固定档位)
   ├─ LevelTwoGeneralLampType有"武庙"或"高山仰止"? → 限定
   ├─ GetValue有1101或1102? → 限定
   ├─ GetValue有1004(祈福)? → 传说
   ├─ GetValue有1001(纳贤)? → 史诗
   ├─ GetValue有5002(神将任务)? → 史诗
   ├─ GetValue有2000/2002/2003(充值)? → 史诗
   ├─ GetValue有3001(山河令)? → 史诗
   └─ GetValue有1005(星河宝箱)? → 史诗

步骤2: 检查将星价格
   ├─ 将星价格 ≥ 10,000? → 传说
   ├─ 将星价格 ≥ 2,000? → 史诗
   ├─ 将星价格 ≥ 100? → 稀有
   └─ 将星价格 < 100? → 普通

步骤3: 检查珍宝定价
   ├─ 珍宝定价 ≥ 200,000? → 限定
   ├─ 珍宝定价 ≥ 100,000? → 传说
   ├─ 珍宝定价 ≥ 10,000? → 史诗
   ├─ 珍宝定价 ≥ 1,001? → 稀有
   └─ 珍宝定价 ≤ 1,000? → 普通

步骤4: 其他 → 待手动确认

================================================================================
四、多途径时的优先级
================================================================================

当武将同时有多个获取途径时，按以下优先级执行：

将星 > 武庙 > 高山仰止 > 祈福 > 纳贤 > 其他

================================================================================
五、注意事项
================================================================================

1. 珍宝定价与获取价值不同:
   - 珍宝定价: 来自珍宝定价表, 如胡金定=100000
   - 获取价值: 来自operate_info表,如胡金定=999(将星)+1000(官阶)
   - 两者不是同一个概念!

2. LevelTwoGeneralLampType 优先于 GetValue:
   - 两者含义一致，优先使用 LevelTwoGeneralLampType

3. v2.0 优先级变化:
   - 将星价格从第三优先级升为第二优先级
   - 珍宝定价从第二优先级降为第三优先级
   - 新增多个固定史诗档: 2000/2002/2003/3001/1005

六、示例说明
================================================================================

【例1】胡金定
   - 获取途径: 将星(999) + 官阶(1000)
   - LevelTwoGeneralLampType: 无武庙/高山仰止
   - 将星价格: 999 → 稀有
   - 珍宝定价: 100,000 → 传说
   - 分类: 传说 (珍宝定价10万)

【例2】管亥
   - 获取途径: 1001(纳贤)
   - 珍宝定价: 120,000 (来自定价表)
   - 分类: 史诗 (1001纳贤优先级高于珍宝定价)

【例3】神刘备
   - 获取途径: 5002(神将任务)
   - 珍宝定价: 可能有
   - 分类: 史诗 (神将任务固定史诗档)
