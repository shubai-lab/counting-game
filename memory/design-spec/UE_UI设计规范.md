**设计原则**：

- 点击关闭按钮

- 提示信息
- 确认内容

**操作区分类**：
- 取消按钮
- 确认按钮

### 5. 特殊场景下的快捷操作
- 支持快捷键操作
- 支持手势操作

## 七、toast

### 1. 定义
轻量级提示信息，短暂显示后自动消失。

### 2. toast规范目的

**一致性**：
- 统一样式
- 统一位置

**易用性**：
- 不打断操作
- 信息清晰

### 3. toast位置分类

**引导/操作提示**：
- 位置：操作区域附近
- 时长：2-3秒

**全局toast**：
- 位置：屏幕中央或顶部
- 时长：2-3秒

**系统相关toast**：
- 位置：系统区域
- 时长：根据重要性

**教学/操作类toast**：
- 位置：教学区域
- 时长：操作完成

**跑马灯**：
- 位置：顶部或底部
- 时长：循环播放

**即时操作toast**：
- 位置：操作区域
- 时长：即时反馈

### 4. 字体规范

> 字体规范：参见公共规范-字体规范总表
>
> 特殊说明：
> - toast标题：26px
> - 序号：26px
> - 提示文字：24px
> - 乐曲名称：28px
> - 操作提示：18px
> - 跑马灯文字：20px

# 适配规范

## 一、适配基础原则

### 1.1 核心原则

**统一适配方案**：
- 使用锚点系统进行适配标注
- 建立统一的适配层级结构
- 确保各机型显示效果一致

**适配优先级**：
1. 功能完整性优先
2. 视觉效果优先
3. 性能优化优先

### 1.2 适配类型分类

**类型一：贴边适配**
- 适用场景：固定在边缘的元素
- 适配方法：相对边缘固定距离

**类型二：内容区域-整体型居中适配**
- 适用场景：整体内容居中显示
- 适配方法：相对中心点适配

**类型三：内容区域-间隔型居中适配**
- 适用场景：多个元素间隔排列
- 适配方法：相对中心点+间隔适配

**类型四：非闭合内容区域-列表适配**
- 适用场景：列表滚动内容
- 适配方法：相对起点+滚动适配

**类型五：闭合内容区域-列表适配**
- 适用场景：固定高度列表
- 适配方法：相对容器边界适配

**类型六：弹窗适配**
- 适用场景：弹窗内容
- 适配方法：相对弹窗边界适配

### 1.3 页签适配规则

**侧页签（一二级）**：
- 固定宽度
- 高度适配

**横页签**：
- 固定高度
- 宽度适配

**特殊页签**：
- 根据设计稿特殊处理

### 1.4 特殊机型适配

**刘海屏适配**：
- 避开刘海区域
- 状态栏高度适配

**iPhone灵动岛适配**：
- 避开灵动岛区域
- 状态栏高度适配

**Home Indicator适配**：
- 底部安全区域适配
- 避免手势冲突

**Pad适配**：
- 分辨率适配
- 横竖屏适配

# 界面动效规范

## 一、系统主界面动效 - 过渡全局通用统一

### 1.1 动效作用与意义

**作用**：
1. 增强视觉体验
2. 引导用户注意力
3. 提供操作反馈
4. 建立界面层级关系

**意义**：
- 提升产品品质感
- 增强用户沉浸感
- 优化交互体验

### 1.2 时间节点规范

**1.2.1 基准时长**：
- 标准动效时长：300ms
- 快速动效时长：200ms
- 慢速动效时长：500ms

**1.2.2 响应时间**：
- 即时反馈：< 100ms
- 界面切换：200-300ms
- 复杂动画：500-1000ms

**1.2.3 动效持续时长**：
- 进入动效：200-300ms
- 退出动效：150-250ms
- 循环动效：根据内容

**1.2.4 加载动效规范**：
- 最小显示时间：500ms
- 超时提示：3s
- 失败重试：5s

### 1.3 速度和缓冲

**1.3.1 缓动曲线类型**：
- Linear：线性
- Ease-in：渐入
- Ease-out：渐出
- Ease-in-out：渐入渐出
- Cubic-bezier：自定义曲线

**1.3.2 速度选择原则**：
- 进入动效：使用ease-out
- 退出动效：使用ease-in
- 循环动效：使用linear
- 特殊动效：自定义曲线

### 1.4 过渡效果样式

**1.4.1 全屏渐隐（退出效果）**：
- 适用场景：退出界面
- 动效方式：opacity从1到0
- 持续时间：150-250ms

**1.4.2 全屏渐显（进入效果）**：
- 适用场景：进入界面
- 动效方式：opacity从0到1
- 持续时间：200-300ms

**1.4.3 路径/位置移入（进入效果）**：
- 适用场景：侧滑进入
- 动效方式：position从边缘到目标
- 持续时间：200-300ms

**1.4.4 路径/位置移出（退出效果）**：
- 适用场景：侧滑退出
- 动效方式：position从目标到边缘
- 持续时间：150-250ms

**1.4.5 放大进入（进入效果）**：
- 适用场景：弹窗显示
- 动效方式：scale从0.8到1
- 持续时间：200-300ms

**1.4.6 缩小进入（进入效果）**：
- 适用场景：弹窗关闭
- 动效方式：scale从1到0.8
- 持续时间：150-250ms

### 1.5 过渡效果搭配注意事项

1. 进入和退出动效要匹配
2. 避免动效冲突
3. 保持动效一致性
4. 考虑用户等待时间
5. 提供跳过动效选项
