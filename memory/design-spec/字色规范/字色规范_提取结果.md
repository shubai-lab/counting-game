# 字色规范（UI版本）

> 提取自Figma文档：十周年--交互设计规范
> **节点ID**: 5:11695

---

## 概述

字色规范分为**亮底**和**暗底**两种场景，分别对应不同的背景色和文字颜色。

## 一、亮底场景

**背景色**: `#d6c09e`

### 1.1 文字颜色规范

| 颜色名称 | HEX值 | 使用规则 | 定位说明 |
|---------|-------|---------|----------|
| 强调色 | `#e76d01` | 用于界面信息中需要重点突出的、关键提示的文字信息 | 常用于描述说明文本中专有名词类的 |
| 二级文字 | `#734d1f` | 用于游戏中所有有主次信息对比的文字信息时，次级信息的颜色 | 主要用于说明描述类文字，起解释规则，叙述内容的作用 |
| 一级文字 | `#4f3427` | 当信息需要有主次信息对比的文字信息时，用于主级信息的颜色 | 描述类文字的标题文字或重点文字，起到一级信息提示作用 |
| 次要色 | `#929292` | 用于当前功能还未解锁、未激活的描述文字信息 | - |
| 负面信息色 | `#c80000` | 用于衰减类、未满足条件类的文字信息 | - |
| 正面信息色 | `#27a700` | 用于增益类、满足条件类的文字信息 | - |

### 1.2 品质色规范

| 品质 | HEX值 | 适用场景 |
|------|-------|----------|
| 传说 | `#ff2103` | 传说品质道具名称 |
| 史诗 | `#ff7d0a` | 史诗品质道具名称 |
| 稀有 | `#b11bf7` | 稀有品质道具名称 |
| 普通 | `#27a700` | 普通品质道具名称 |
| 精良 | `#007eb9` | 精良品质道具名称 |

### 1.3 特殊效果

#### 字体描边
- **文字颜色**: `#6d350d`
- **描边颜色**: `#ff8400`
- **描边宽度**: 1px（尽量保证）
- **使用场景**: 游戏牌局内进度条上的文字

#### 黑色/白色字
- **颜色**: `#000000` 或 `#ffffff`
- **使用场景**: 游戏中品质色底上进行描述的文字

## 二、暗底场景

**背景色**: `#5c4638`

### 2.1 文字颜色规范

| 颜色名称 | HEX值 | 使用规则 | 定位说明 |
|---------|-------|---------|----------|
| 一级文字 | `#fff0d5` | 当信息需要有主次信息对比的文字信息时，用于主级信息的颜色 | 描述类文字的标题文字或重点文字，起到一级信息提示作用 |
| 二级文字 | `#c1ae8e` | 用于游戏中所有有主次信息对比的文字信息时，次级信息的颜色 | 主要用于说明描述类文字，起解释规则，叙述内容的作用 |
| 强调色 | `#e76d01` | 用于界面信息中需要重点突出的、关键提示的文字信息 | 常用于描述说明文本中专有名词类的 |
| 正面信息色 | `#27a700` | 用于增益类、满足条件类的文字信息 | - |
| 负面信息色 | `#e90f0f` | 用于衰减类、未满足条件类的文字信息 | - |
| 次要色 | `#9d9d9d` | 用于当前功能还未解锁、未激活的描述文字信息 | - |

### 2.2 品质色规范

| 史诗 | `#ff7d0a` | 史诗品质道具名称 |
| 稀有 | `#b11bf7` | 稀有品质道具名称 |
| 普通 | `#27a700` | 普通品质道具名称 |
| 精良 | `#007eb9` | 精良品质道具名称 |

### 2.3 特殊效果

#### 字体描边
- **文字颜色**: `#fff0d5`
- **描边颜色**: 暗底场景暂无描边需求
- **使用场景**: 游戏牌局内进度条上的文字

---

## 三、使用注意事项

1. **UI版本同步**: 本规范为UI版本，UI若更新需即时同步
2. **主次对比**: 一级和二级文字需要根据信息重要性进行主次对比使用
3. **品质色限制**: 品质色仅用于道具名称，不应在其他场景滥用
4. **特殊效果慎用**: 字体描边和特殊颜色仅在特定场景使用，不应随意添加
