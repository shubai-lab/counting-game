## 1. 文档总纲

### 产品需求分析

1. **主要解决的问题**
   - 公会活跃度严重不足
   - 成员流失严重，缺乏留存机制；新手难以融入
   - 管理工具缺失

2. **面向用户**：全体用户

3. **群体大小**：月活均130W用户

4. **成功的标准**：月活人数占比达到50%

5. **竞品参考**
   - 王者荣耀：活跃度激励、战队赛排名奖励
   - 梦幻西游：帮派合并

6. **产品特点**
   - 三国主题深度结合
   - 红包社交玩法

7. **现在适合修改的原因**
   - 核心玩家有强烈社交需求
   - 公会系统已有基础框架，改造成本可控

8. **推广方式**
   - 公会入口红点
   - 一次性引导任务

9. **成功的关键**
   - 匹配准确度
   - 新手引导
   - 管理工具的便利性

## 2. 功能逻辑

### 2.1 基础逻辑

#### 1. 公会和玩家活跃度

**a. 玩家活跃度**

玩家实际活跃天数/实际存活天数（以7天为单位），范围0%-100%

- **活跃定义**：只要登录过就算活跃
- **计算公式**：玩家月活跃值 = 实际活跃天数 / 实际存活天数（上限1.0）
- **新手/回归特殊处理**：
  - 创角15天及以内：固定值为80%
  - 创角15天后，按实际计算

**b. 公会活跃度**

公会所有成员平均活跃程度，范围0%-100%

- **计算公式**：公会活跃度 =（ Σ(成员个人活跃值) / 成员数）*100%
- **含义**：平均每个成员的活跃程度；范围0%-100%
- **示例**：
  - 成员A（30天全勤）：1.0
  - 新人成员B（10天全勤）：1.0
  - 成员C（30天登录15天）：0.5
  - 活跃值总和：2.5 / 3人 = 83%

**公会活跃度计算流程**：
定时任务 → 遍历成员 → 计算玩家活跃度(活跃天数/存活天数) → 累加 → 公会活跃度=总活跃度/成员数

**公会活跃度分层**：
- 低活跃：0.0 ~ 0.3
- 中活跃：0.3 ~ 0.6
- 高活跃：0.6 ~ 1.0

#### 2. 玩家分层与匹配

**a. 新手（<50级）先进入公会**

- **第一步**：筛选带新人友好标签优先推荐公会
  - 筛选满足条件的公会
- **第二步**：按活跃人数降序排列
  - 活跃人数 = 公会人数 × 公会活跃度

**b. 大盘用户（等级>50级；官阶≤国护军）**

- **第一步**：筛选满足条件的公会
  - 玩家等级 ≥ 公会要求的最低等级
  - 玩家官阶 ≥ 公会要求的最低官阶
  - 公会未满员
- **第二步**：按活跃人数降序排列
  - 活跃人数 = 公会人数 × 公会活跃度

**c. 高官阶用户（官阶>国护军）**

- **第一步**：筛选满足条件的公会
  - 玩家等级 ≥ 公会要求的最低等级
  - 玩家官阶 ≥ 公会要求的最低官阶
  - 公会未满员
- **第二步**：按月红包数量降序
  - （公会上月发出的红包个数）
- **第三步**：按活跃人数降序排列
  - 活跃人数 = 公会人数 × 公会活跃度

**匹配流程**：
检查加入条件(等级/官阶/活跃度) → 发送申请 → 免审核直接加入或等待审批

**推荐算法**：
获取玩家信息(等级/官阶/活跃度) → 按玩家类型过滤 → 检查加入条件 → 计算推荐分数(新手标签匹配+活跃度+红包数) → Top20推荐

#### 3. 新人友好公会标签

**a. 判定指标（近30天）**

- 收新人数：近30天加入的<50级成员数
- 踢新人数：近30天被踢的<50级成员数
- 留存新人数：近30天加入且仍在会的<50级成员数

**b. 评分公式**

- 新人友好分 = 1×收新人数 + 2×留存新人数 - 3×踢新人数
- 如果新人的活跃分小于0.1，则踢出公会不计入公式

**c. 判定规则**

- 新人友好分 ≥ 10 → 自动打上"新人友好"标签
- 更新机制：每周凌晨2点定时更新

---

#### 4. 招募以及申请限制

**a. 公会筛选玩家**

可以设置玩家进入的等级以及将灵以及官阶信息

**b. 设置后默认变动**

- 默认设置为不限制以及自由加入
- 如果玩家改成需要申请，则保留选中

**c. 继承情况**

如果当前游戏中设置为需要申请加入，则更新为满足条件后需要申请通过

---

#### 5. 公会合并

**a. 自动合并**

会长离线>30天 + 月活<5人 → 7天提醒：玩家可以自动选择公会 → 结束后默认分配成员到推荐公会 → 删除原公会

- 如果成员的活跃度=0，则不给玩家推送到任何公会
- 推荐公会需要玩家满足对方的要求和条件；玩家合并进入的公会可以不是一个公会

**当前自动解散逻辑删除，改成自动合并**：
公会建立后，一个自然日内，公会总人数小于5人或当天公会登录人数为0，则被视为公会解散状态，该状态保持30天，则公会自动解散

**b. 手动申请**

双方会长确认 → 成员选择去留 → 合并资源(取最高等级/经验) → 7天冷却期

**手动申请流程**：
1. **触发条件**：双方会长同意确认
   - 公示3天
2. **成员选择**：可选择留下或自由退会
   - 处理方式：成员推荐到相似标签推荐公会（与自动合并一致）
   - 玩家自由退会不触发退会惩罚
3. **合并冷却**：合并后7天内不能再合并
4. **合并数值处理**
   - A合并入B公会；则删除A公会所有的一切，仅保留B公会做为主体
   - **职位处理**：
     - 会长：接收方为会长
       - 会长可以选择将被接收方会长设为副会长
     - 普通成员：合并后统一重新分配
       - 超过公会上限后，会长只允许携带对方有空余人数的公会职员人数
       - 超过人数不允许合并
   - 走合并的玩家离开公会进入新公会不受公会惩罚

---

#### 6. 会长弹劾

**优化**：当一个公会的会长连续7天不在线，则公会任何成员可发起会长弹劾

- 若3天内，若最终同意的玩家大于拒绝的玩家，弹劾成功（玩家需要在公会内超过30天才能参与弹劾）
- 转让给：贡献最高的副会长（如果副会长也连续7天不在线），则转让给下一成员
  - 转让列表：副会长（依据贡献排序）；普通成员（依据贡献排序）
  - 必须满足条件：个人活跃度大于等于0.6；且7天内有过在线
