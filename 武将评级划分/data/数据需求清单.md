# 武将评级划分 - 数据需求

## 需要准备的数据

### 1. 武将基础数据
| 数据项 | 说明 | 状态 |
|--------|------|------|
| 武将总数 | 当前游戏中有多少武将 | ✅ 733个（已获取） |
| 各档位武将数量分布 | 现有 T0-T10 各有多少个 | ✅ 见下表（已获取） |
| 武将列表（含档位） | 完整武将列表，标注当前档位 | ✅ 分级母表（已获取） |

### 2. 获取方式数据
| 数据项 | 说明 | 状态 |
|--------|------|------|
| 获取方式分布 | 各武将获取方式（抽卡/商城/活动/任务等） | ✅ 8种页签分类（已获取） |
| 价格/保底机制 | 获取武将需要的资源/保底次数/价格 | ⚠️ 待补充（定价表有但未关联） |

### 数据来源
- `sgs_general_conf.xlsx` - 武将配置表（GetValue字段）
- `sgs_general_activity_operate_info.xlsx` - 运营活动获取途径表
- `sgs_general_activity_operate.xlsx` - 获取途径配置表

### 获取途径匹配逻辑
```
1. sgs_general_conf.GetValue → 解析"获取途径:ID"
2. 如果为空 → sgs_general_activity_operate_info.ActiveDropWay
3. 如果仍然为空 → 使用GetTitle + "更多方式"页签
```

### 3. 强度参考数据（可选）
| 数据项 | 说明 | 状态 |
|--------|------|------|
| 武将使用率 | 各武将被使用的频率 | ⬜ 如有请提供 |
| 武将胜率 | 各武将在对局中的胜率 | ⬜ 如有请提供 |

---

## 数据格式建议
- Excel / CSV 格式均可
- 武将名称、档位、获取方式、价格/保底 为必填列
