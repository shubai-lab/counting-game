## 三、分类逻辑（8级优先级）

```
优先级1: LampType特殊规则（最高优先级）
├── 武庙/高山仰止 → 限定
├── 威前缀（威孙权、威马超等）→ 限定
├── 神武灯 → 传说
├── 神灯 → 史诗
├── 谋前缀（谋司马懿、谋周瑜等）→ 传说
├── 无双上将 → 史诗
└── 界限突破 → 稀有

优先级2: 固定档位获取途径
├── 祈福(1004) → 传说
├── 纳贤(1001) → 史诗
└── 神将任务(5002) → 史诗

优先级3: 将星招募(2)价格
├── ≥9,999 → 传说
├── 2,000~9,998 → 史诗
├── 100~1,999 → 稀有
└── <100 → 普通

优先级4: 宝玉兑换(1101)价格
├── ≥200,000 → 限定
├── 100,000~199,999 → 传说
├── 10,000~99,999 → 史诗
├── 1,000~9,999 → 稀有
└── <1,000 → 普通

优先级5: 珍宝(1003)价格（阈值同宝玉兑换）

优先级6: 普通招募(1) → 普通

优先级7: 武将标签含|1 → 普通

优先级8: 武将道具定价（兜底）
├── ≥200,000 → 限定
├── 100,000~199,999 → 传说
├── 10,000~99,999 → 史诗
├── 1,000~9,999 → 稀有
└── <1,000 → 普通
```

## 四、数据合并规则

```python
# 主表(列60) + 运营表 合并
# 运营表优先级更高（纳贤等特殊途径不在主表）
def merge_ways(main_ways, operate_ways):
    merged = dict(main_ways)
    for way_id, price in operate_ways.items():
        if way_id not in merged:
            merged[way_id] = price
    return merged
```

## 六、有效武将过滤条件

同时满足以下条件的武将才会被分类：
1. `ExType`（武军团分包）非空
2. `LevelTwoGeneralLampType`（二级将灯）非空
3. `Star` > 0
4. **排除国战系列**（LampType含"国战"）
