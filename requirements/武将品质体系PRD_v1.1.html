一、项目背景

1.1 问题描述

项目组目前没有统一的武将品质分级标准，导致：

  • 定价参考不统一
  • 获取难度标注混乱

1.2 项目目标

建立一套与行业标准对齐的武将品质体系，核心是确定档位标准：哪些武将归哪个档。

1.3 适用范围

内部策划讨论、定价参考、获取难度标注。

4.3 获取途径分类规则

武庙珍藏 / 高山仰止（固定限定档）

  • 高山仰止系列 → 限定（固定档位，优先级最高）

祈福（固定传说档）

  • 祈福武将 → 传说（固定档位，优先级高于价格）

纳贤 / 神将任务 / 神武 / 谋定天下（固定史诗档）

  • 纳贤武将 → 史诗（固定档位）
  • 神将任务武将 → 史诗（固定档位）
  • 神武/谋定天下武将 → 史诗（固定档位）

将星商城（按价格分层）

  • 将星价格 ≥ 1万 → 传说
  • 将星价格 2000~9999 → 史诗
  • 将星价格 100~1999 → 稀有
  • 将星价格 < 100 → 普通

珍宝 / 运营活动（按价格分层）

  • 价格 ≥ 20万 → 限定
  • 价格 10万~20万 → 传说
  • 价格 1万~10万 → 史诗
  • 价格 1001~1万 → 稀有
  • 价格 ≤ 1000 → 普通
