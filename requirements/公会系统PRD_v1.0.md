## 一、产品概述

### 1.1 产品定位

公会系统是《三国杀一将成名》移动端的社交核心模块，旨在通过公会玩法增强玩家归属感、激励长期活跃、构建玩家社交关系链。

### 1.2 核心价值

| 价值点 | 说明 |
|--------|------|
| 社交连接 | 玩家通过公会找到志同道合的战友 |
| 目标驱动 | 每日/每周任务为玩家提供持续上线理由 |
| 荣誉激励 | 公会排行、个人贡献排行激发竞争心理 |
| 资源激励 | 红包系统增强公会凝聚力，促进成员互动 |

### 1.3 目标用户

- 主目标：活跃的中小R玩家（每日活跃时长 30-120 分钟）
- 次目标：休闲玩家（公会作为社交场所，不追求排行）
- 辅助目标：公会管理层（运营公会、激励成员）

## 三、界面详细说明

### 3.1 顶部区域 - 公会信息卡

**位置**：界面最顶部，固定显示

**设计规范**：
- 背景：深色底（深棕/深紫色）+ 龙纹祥云装饰图案
- 尺寸：全宽，高度约 120-140px
- 内边距：16px

**信息元素**：

| 元素 | 样式 | 说明 |
|------|------|------|
| 公会图标 | 64x64px，金色描边方形 | 显示公会徽章 |
| 公会名称 | 白色大字，24-28px | 最长8个汉字 |
| 等级标签 | 橙金色底，白色字，胶囊形 | 格式："N级" |
| 会长信息 | 较小字号，灰色/白色 | 格式："会长：XXX" |
| 成员数 | 白色数字 + "人"标签 | 数字加粗 |
| 总贡献 | 白色数字 + "贡献"标签 | 数字加粗 |

**数据字段**：

| 字段名 | 类型 | 示例 | 说明 |
|--------|------|------|------|
| guildName | string | "傲天阁" | 公会名称 |
| guildLevel | int | 2 | 公会等级 1-10 |
| leaderName | string | "傲天·星辰" | 会长昵称 |
| memberCount | int | 16 | 当前成员数 |
| maxMemberCount | int | 50 | 最大成员数（随等级变化） |
| totalContribution | long | 152800 | 公会总贡献值 |

### 3.2 Tab 切换区

**设计规范**：
- Tab 数量：4个（公会战、公会任务、公会技能、更多...）
- Tab 样式：文字按钮，无图标
- 选中态：底部橙色下划线
- 未选中：灰色文字
- Tab 高度：44px

**交互逻辑**：
- 点击切换 Tab，当前页面内容随之变化
- 切换动画：淡入淡出，200ms
- 默认显示：公会任务 Tab

### 3.3 内容区域 - 活跃任务

#### 3.3.1 每日任务

**任务卡片结构**：

| 元素 | 说明 |
|------|------|
| 任务图标 | 圆形，32x32px，彩色底（红/蓝/绿） |
| 任务名称 | 黑色文字，16px |
| 奖励标签 | "奖励：XXX贡献"，灰色小字 |
| 进度条 | 灰色底 + 橙色填充，当前进度 0/X |
| 前往按钮 | 橙色底，白色字，40x28px，圆角8px |

**任务类型标识**（图标颜色）：

| 颜色 | 含义 |
|------|------|
| 红色 | 战斗类任务（对局、击杀） |
| 蓝色 | 社交类任务（聊天、点赞） |
| 绿色 | 消费类任务（购买、捐赠） |
| 紫色 | 周挑战任务 |
| 黄色 | 高难度任务 |

**数据字段**：

```typescript
interface DailyTask {
  taskId: string;
  taskName: string;
  taskIcon: string;      // 图标URL或图标ID
  iconColor: 'red' | 'blue' | 'green';
  reward: number;         // 贡献奖励数量
  currentProgress: int;  // 当前完成进度
  targetProgress: int;   // 目标进度
  actionLink: string;    // 点击"前往"跳转的页面
  status: 'pending' | 'completed' | 'claimed';
}
```

**边界状态**：

| 状态 | 显示 |
|------|------|
| 未完成 | 灰色进度条，"前往"按钮可点击 |
| 已完成未领取 | 橙色进度条满，"领取"按钮（替换"前往"） |
| 已领取 | 灰色进度条，"已领取"文字，按钮不可点击 |
| 进行中 | 橙色进度条部分填充，"继续"按钮 |

## 五、交互流程

### 5.1 主流程

```
用户打开游戏
    ↓
进入公会主页（默认显示）
    ↓
查看公会信息 / Tab切换 / 内容浏览
    ↓
点击任务"前往" → 跳转目标页面完成任务
    ↓
返回公会主页 → 任务进度更新 → 领取奖励
```

### 5.2 任务领取流程

```
任务完成（进度达到目标）
    ↓
"前往"按钮变为"领取"按钮
    ↓
点击"领取" → 弹出确认弹窗
    ↓
确认领取 → 贡献+动画 → 按钮变为"已领取"
```

### 5.3 Tab 切换流程

```
用户点击 Tab（公会战/公会任务/公会技能/更多）
    ↓
当前内容淡出（200ms）
    ↓
加载目标内容（显示loading骨架屏）
    ↓
新内容淡入（200ms）
```

## 六、状态定义

### 6.1 任务状态

| 状态 | 标识 | 说明 |
|------|------|------|
| pending | 待完成 | 进度未达目标，按钮显示"前往" |
| completed | 已完成待领取 | 进度达标，未领取奖励 |
| claimed | 已领取 | 奖励已发放，不可再操作 |

### 6.2 网络状态

| 状态 | 显示 |
|------|------|
| 加载中 | 骨架屏 + loading动画 |
| 加载成功 | 正常内容显示 |
| 加载失败 | 错误提示 + 重试按钮 |
| 空数据 | 空状态插画 + 文案（如"暂无任务"） |

### 6.3 公会状态

| 状态 | 说明 |
|------|------|
| 正常 | 正常运行，可操作所有功能 |
| 维护中 | 显示维护公告，功能暂停 |
| 已解散 | 跳转公会列表页 |

## 七、边缘情况

### 7.1 任务相关

| 情况 | 处理方式 |
|------|---------|
| 任务未刷新 | 静默更新，不显示刷新提示 |
| 任务进度异常 | 显示"数据异常"，自动刷新 |
| 奖励领取失败 | 弹窗提示，点击重试 |

### 7.2 排行相关

| 情况 | 处理方式 |
|------|---------|
| 排行数据未更新 | 显示上次缓存数据 + 时间戳 |
| 自己是第1名 | 高亮显示 + 特殊徽章 |
| 自己是最后一名 | 不做特殊标识 |

### 7.3 网络相关

| 情况 | 处理方式 |
|------|---------|
| 网络断开 | 缓存上次数据，显示离线状态提示 |
| 请求超时 | 自动重试1次，失败后显示重试按钮 |
| 数据格式错误 | 记录日志，跳过错误数据 |

### 7.4 边界数据

| 情况 | 处理方式 |
|------|---------|
| 公会名称过长 | 最多显示8个字符，超出省略 |
| 成员数为0 | 显示"暂无成员" |
| 贡献为0 | 显示"--"而非"0" |
| 排行榜为空 | 显示"暂无排行数据" |
