## 一、背景与目的

### 1.1 项目背景

项目组需要对武将进行统一的品质分级，用于：
- 定价参考
- 获取难度标注
- 玩家资源规划

目前存在两套参照体系：
- **三国杀OL**：限定/传说/史诗/稀有/普通（5档）
- **手杀**：史诗/精品/普通（3档）

### 1.2 项目目标

建立一套与行业标准对齐的武将品质体系，输出：
1. 武将品质分级表（含673个有效武将）
2. 各档位价格区间标准
3. 与OL/手杀的对照关系

## 三、分类逻辑 v2.0

### 3.1 数据来源

| 数据表 | 用途 |
|--------|------|
| `sgs_general_conf` | 主武将表，含GeneralID/NamePrefix/GeneralName/LevelTwoGeneralLampType/GetValue |
| `sgs_general_activity_operate_info` | 获取途径详情表，ActiveDropWay字段 |
| `sgs_general_activity_operate` | 获取途径定义表，DropWayID/DropWayName |
| `sgs_item_general_conf` | 武将道具表，建立ItemID→GeneralID映射 |

### 3.2 有效武将过滤规则

排除以下条件的武将（无效武将）：
- `ExType` 为空
- `LevelOneGeneralLampType` 为空
- `LevelTwoGeneralLampType` 为空

**有效武将数量**：673个

### 3.3 四优先级分类规则

#### 第一优先级：固定档位来源（LevelTwoGeneralLampType + 获取途径）

| 判断条件 | 档位 | 来源 |
|----------|------|------|
| LampType含"武庙"或"高山仰止" | 限定 | 二级将灯 |
| 获取途径含1102 | 限定 | 武庙 |
| 获取途径含1101 | 珍宝 | 宝玉兑换（查道具定价表按珍宝规则定档） |
| 获取途径含1003 | 珍宝 | 珍宝（查道具定价表按珍宝规则定档） |
| 获取途径含1004 | 传说 | 祈福 |
| 获取途径含1001/5002/2000/2002/2003/3001/1005 | 史诗 | 纳贤/神将任务/首充/充值奖励/山河令/星河宝箱 |

#### 第二优先级：将星价格（获取途径含2）

| 价格区间 | 档位 |
|----------|------|
| ≥10,000 | 传说 |
| ≥2,000 | 史诗 |
| ≥100 | 稀有 |
| >0 | 普通 |

#### 第三优先级：珍宝/宝玉兑换(1101/1003)价格

珍宝类型武将需查**新三国杀道具定价表**获取实际宝玉价格：

| 价格区间 | 档位 |
|----------|------|
| ≥200,000宝玉 | 限定 |
| ≥100,000宝玉 | 传说 |
| ≥10,000宝玉 | 史诗 |
| ≥1,001宝玉 | 稀有 |
| >0宝玉 且 <1,001 | 普通 |

| 价格区间 | 档位 |
|----------|------|
| ≥200,000宝玉 | 限定 |
| ≥100,000宝玉 | 传说 |
| ≥10,000宝玉 | 史诗 |
| ≥1,001宝玉 | 稀有 |
| >0宝玉 且 <1,001 | 普通 |

#### 第四优先级：普通招募（获取途径含1）

所有包含普通招募途径的武将归为**普通**档。

#### 第五优先级：手动确认

无法通过上述规则分类的武将，需手动确认档位。

### 3.5 获取价值解析规则

无法通过上述规则分类的武将，需手动确认档位。

### 3.4 获取价值解析规则

GetValue字段格式示例：
```
获取途径:2 获取价值:59
获取途径:1003 获取价值:18888
```

解析逻辑：
1. 优先从`sgs_general_conf.GetValue`字段获取获取途径和获取价值
2. 若主表无数据，从`sgs_general_activity_operate_info.ActiveDropWay`获取
3. 正则匹配：`获取途径[：:](\d+)` 和 `获取价值[：:](\d+)`

## 六、分类流程

```
1. 读取 sgs_general_conf.xlsx（主表）
   ↓
2. 过滤有效武将（3个字段非空）
   ↓
3. 读取 sgs_general_activity_operate_info.xlsx（获取途径详情）
   ↓
4. 读取 sgs_general_activity_operate.xlsx（途径定义）
   ↓
5. 解析 GetValue 字段（获取途径 + 获取价值）
   ↓
6. 执行四优先级分类
   ├─ 第一优先级：固定档位来源
   ├─ 第二优先级：将星价格
   ├─ 第三优先级：珍宝价格
   └─ 第四优先级：手动确认
   ↓
7. 输出分类结果
```
